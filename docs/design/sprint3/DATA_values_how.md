## 2. Prod model facts (for fact checking copy)

- Prod alias `prod` on `workspace.nfl_dev.endzone_winprob` is now version 2 (live `latest.json`: `model_name` `workspace.nfl_dev.endzone_winprob`, `model_version` `2@prod`, `feature_set` `h2_full`). Week 9 was published with version 1, weeks 10 and 11 with version 2.
- Recipe: logistic regression, feature set `h2_full`, 20 columns, C 1.0, max_iter 1000, lookback 10, seed 42 (`docs/experiments/walk_forward.md` section Refresh and challenger). Imputation, standard scaling, L2 (`docs/model_card.md` line 17).
- Refresh is manual. "Weekly automation of the refresh is future work. No workflow runs it." (`docs/adr/ADR-009-model-registry.md` line 56, `docs/runbook.md` line 1188, `docs/experiments/walk_forward.md` line 5). Tuesday scoring only loads `prod`, it does not retrain (`ADR-009` section What the scorer does). Exception: if the alias is missing, that week is fit as a fallback and flagged.
- Home win probability, never a spread or a pick. The page label WINS is the rounded home probability, "not a recommendation" (`docs/model_card.md` line 28).
